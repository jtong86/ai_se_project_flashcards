# Flash Cards

Flash Cards is a responsive study application created as part of TripleTen's AI-Assisted Software Engineering program. The application allows users to view different study decks and review flashcards using an interactive carousel.

Each deck contains a collection of questions and answers. Users can navigate between cards, flip a card to reveal its answer, and select different decks from the main page.

## Features

* Displays multiple flashcard decks
* Dynamically renders decks using JavaScript
* Uses URL hash navigation to switch between pages
* Opens individual decks in an interactive carousel
* Navigate between cards using previous and next buttons
* Flip cards to reveal answers
* Displays the current card number and total number of cards
* Uses different colors for different decks
* Includes an About page
* Includes a 404 page for invalid routes
* Allows deck cards to be removed from the page

## Deployment

To run the project locally:

1. Clone the repository.
2. Open the project folder in VS Code.
3. Start the project using the Live Server extension.
4. Open the local development URL in your browser.

The project requires a modern web browser with JavaScript enabled.
